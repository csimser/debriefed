How do I use this?

Click "Download Debriefed" above. Save the HTML file. Double-click it.

The app opens in your browser and runs entirely on your computer. First-launch shows a quick explainer for Dictionary mode (free, no setup) vs AI-enhanced mode (optional, your own API key).

That's it. No account. No signup. No internet required.

For TAP offices, Fleet and Family Support, veteran service organizations: this same file works for anyone you point to it. Share the link, point service members at it. No setup on your end.

I built this because transitioning service members deserve tools that work without a price tag attached and without an "Email us to set this up" wall. Now anyone can download it and use it in 30 seconds.

If your organization wants to host a copy on your own servers, the GitHub repo has everything you need. MIT licensed. Take it.
