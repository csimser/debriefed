# Debriefed Quickstart

1. [Click here to download Debriefed](https://github.com/csimser/debriefed/releases/latest/download/Debriefed.html)
2. Double-click the downloaded `Debriefed.html` file
3. Use it

That's it. The app opens in your browser, runs entirely on your computer, and works offline.

You'll see a first-launch screen explaining Dictionary mode (free, no setup) vs AI-enhanced mode (optional, needs an Anthropic API key). Pick whichever you want and start translating.

If you want to hack on the source code, see DEVELOPMENT.md.
